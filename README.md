# list-mirror

Mirror of the public [Re-filter-lists](https://github.com/1andrevich/Re-filter-lists) domain and IP lists, refreshed every 4 hours by a scheduled workflow and published as release assets:

- `https://github.com/mojameschu-sudo/list-mirror/releases/download/lists/refilter_domains.lst`
- `https://github.com/mojameschu-sudo/list-mirror/releases/download/lists/refilter_ipsum.lst`
- `SHA256SUMS`

Content is copied unchanged from the upstream releases.
